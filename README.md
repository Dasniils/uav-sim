# UAV SIM

Официальный сайт проекта UAV SIM — симулятора БПЛА с реалистичной физикой полёта. Разработчик — ООО «АвиаСим Плюс».

**Адрес после включения GitHub Pages:** https://dasniils.github.io/uav-sim/

## Состав сайта

Статический сайт без сборки, зависимостей, серверной части и аналитических трекеров.

- `index.html` — содержание, навигация, SEO и обязательный блок поддержки.
- `styles.css` — адаптивное оформление, локальный шрифт, поддержка уменьшенного движения.
- `app.js` — мобильное меню, четыре локации, галерея с клавиатурной навигацией.
- `assets/` — изображения, официальные логотипы и локальный шрифт.
- `.nojekyll` — отключение обработки статических файлов через Jekyll.

Все пути к CSS, JavaScript и изображениям относительные: сайт работает в подпапке `/uav-sim/`.

## Локальный просмотр

Из корня репозитория запустить любой статический HTTP-сервер, например:

```sh
python -m http.server 8765
```

Открыть http://localhost:8765/.

## Публикация на GitHub Pages

1. Открыть **Settings → Pages**.
2. В **Build and deployment → Source** выбрать **Deploy from a branch**.
3. Выбрать ветку **main**, папку **/ (root)** и сохранить.
4. Дождаться успешного развёртывания `pages-build-deployment` во вкладке **Actions**.

Изменения файлов в `main` публикуются автоматически. Домен и платный хостинг для этого не требуются.
